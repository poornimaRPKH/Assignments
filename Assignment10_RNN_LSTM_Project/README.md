# Assignment 10 — RNN & LSTM Time Series Prediction

## Dataset used
This corrected project uses the exact provided **household_power_consumption.txt** dataset.

- Frequency: minute-level household electricity readings
- Target: `Global_active_power`
- Modeling series: daily mean `Global_active_power`
- Split: chronological 80% training / 20% testing
- Lookback: previous 30 days
- Models: Simple RNN and LSTM
- Metrics: RMSE and MAE

## Images
`images/raw_series.png` is already generated from the supplied household power dataset.
The RNN/LSTM training curves, prediction comparison, zoomed comparison, and metric comparison are generated by the notebook when all cells are run, because those figures depend on the trained neural-network weights.

## Run
Open `Assignment10_RNN_LSTM_HouseholdPower.ipynb` in Google Colab and choose **Runtime → Run all**. The notebook will generate all remaining figures and the final evaluation CSV.
